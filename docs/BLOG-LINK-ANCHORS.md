# Âncoras de link no blog (corpo)

Regras: linkar menções temáticas no **corpo** (opening, sections, bullets narrativos, table, closing).  
**Não** linkar: título / H2 / H3, FAQ, meta (`description` / `intro`), self-link da página atual.  
Preferir a **frase mais longa**; não fatiar nomes oficiais. Em listas checklist, linkar só a **primeira menção útil** no texto corrido (evitar spam).

## Prioridade guia × tool × landing

1. Texto educativo “o que é / como calcular / como funciona” → **blog**  
2. “Simule / calcule agora” → **calculadora**  
3. Pitch de produto / feature → **landing** ou home

## Observações

- Em negrito + link: o `BlogRichText` já renderiza link dentro de `**...**`.
- FAQ: texto puro, sem markdown.
- `public/blog/*.md`: espelho `llms.txt` — **fora do sitemap**, `Disallow: /*.md$`, `X-Robots-Tag: noindex`.
